# 🏥 نظام إدارة العيادات الطبية متعدد الفروع (Multi-Branch Clinic System)

نظام متكامل وشامل لإدارة العيادات والمراكز الطبية متعددة الفروع، تم تطويره باستخدام لغة **VB.NET** وقواعد بيانات **Microsoft SQL Server**، مع واجهة مستخدم حديثة وتفاعلية تتناسب مع متطلبات العمل الطبي الفعلي.

---

## ✨ أبرز مميزات النظام

- **إدارة الفروع والأطباء:** تنظيم بيانات الفروع وتعيين الأطباء والموظفين لكل فرع بدقة.
- **إدارة المرضى والتسجيل:** سجل كامل لكل مريض يشمل البيانات الشخصية والتاريخ الطبي.
- **إدارة الجلسات وصلاحيات الأمان (`SessionManager`):** نظام أمني يضمن تخصيص الصلاحيات بناءً على دور المستخدم والفرع التابع له.
- **نظام تقارير ذكي متقدم:**
  - استعلامات وبحث ذكي وسريع في كافة شاشات النظام.
  - تصدير التقارير إلى **Excel** باستخدام مكتبة `EPPlus`.
  - تصدير التقارير إلى **PDF** باستخدام مكتبة `iTextSharp` مع دعم كامل للغة العربية.
- **تسجيل الأخطاء والدعم الفني (`Logger`):** نظام تلقائي لتسجيل أخطاء التشغيل في ملفات نصية لسهولة الصيانة والتتبع.
- **واجهات مستخدم عصرية (UI/UX):** تم تصميم الواجهات اعتماداً على مكتبة `ReaLTaiizor` لتقديم تجربة مستخدم سلسة واحترافية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **لغة البرمجة:** Visual Basic .NET (VB.NET) / .NET Framework
- **قواعد البيانات:** Microsoft SQL Server
- **واجهة المستخدم:** Windows Forms / ReaLTaiizor UI Pack
- **تصدير البيانات:** EPPlus (Excel) & iTextSharp (PDF)
- **التشفير والحماية:** BCrypt.Net (لتشفير كلمات المرور)

---

## ⚙️ متطلبات التشغيل والتركيب (Setup)

1. **قاعدة البيانات:**
   - قم بإنشاء قاعدة بيانات باسم `ClinicDB` على سيرفر SQL Server لديك.
   - استورد ملف الـ SQL المرفق مع المشروع لإنشاء الجداول والبيانات الأولية.
2. **الاتصال بقاعدة البيانات:**
   - افتح ملف `App.config` وتأكد من تعديل نص الاتصال `ClinicDBConnection` ليتوافق مع اسم السيرفر لديك:
   ```xml
   <connectionStrings>
     <add name="ClinicDBConnection" connectionString="Data Source=YOUR_SERVER_NAME;Initial Catalog=ClinicDB;Integrated Security=True;" providerName="System.Data.SqlClient" />
   </connectionStrings>
