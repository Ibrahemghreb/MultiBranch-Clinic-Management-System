# مخططات واجهات Managementclinic

> **ملاحظة:** ReaLTaiizor مستخدم فعلياً في `frmLogin` فقط (`MaterialForm`).
> باقي النماذج WinForms عادية + أزرار بصور. هذا الملف يوثّق **الوضع الحالي** و**المقترح التجاري** للتوحيد.

## معايير التصميم المقترحة (ReaLTaiizor)

| العنصر | الحجم | الخط |
|--------|-------|------|
| نموذج CRUD قياسي | **1024 × 720** | Segoe UI 10 / Cairo 11 للعربي |
| تسجيل الدخول | **480 × 520** | MaterialForm |
| الفورم الرئيسي | **1280 × 800** (قابل للتكبير) | — |
| TextBox / ComboBox | **280 × 36** | ارتفاع موحّد |
| Label عرض ثابت | **120 × 24** | يمين للعربي (RTL لاحقاً) |
| أزرار إجراء (MaterialButton) | **140 × 40** | — |
| أزرار أيقونة (حالي) | **128 × 74** | يُستبدل تدريجياً |
| DataGridView | عرض كامل − هامش 24 | ارتفاع صف 32 |
| شريط أزرار سفلي | Y = ClientHeight − 88 | 6 أزرار × 128 |

## 1) frmLogin — الحالي vs المقترح

### الحالي
- **النوع:** `ReaLTaiizor.Forms.MaterialForm`
- **ClientSize:** 515 × 346 (+ Padding علوي 78 للعنوان)
